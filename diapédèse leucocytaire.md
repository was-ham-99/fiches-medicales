#cytologie

La diapédèse est un processus en plusieurs étapes. Le **roulement** initial des leucocytes sur l'endothélium est médié par les **sélectines** (A et B). L'**adhésion stable**, ferme, qui permet ensuite la migration, est assurée par les **intégrines** (C) présentes sur les leucocytes, qui se lient aux immunoglobulines comme ICAM-1 sur l'endothélium. Les chimiokines (D) activent les intégrines. PECAM-1 (E) est impliqué dans la migration trans-endothéliale proprement dite.
    
- **Mots-clés / Pièges :** **Roulement = sélectines ; Adhésion stable = intégrines** ; Migration = PECAM-1.
