Voici la correction détaillée des questions 1 à 80, avec pour chaque proposition une explication et les mots-clés en gras.

**Question 1**
[[Fécondation]]
**Réponse : A** (cochez la fausse)

- **A** : La fécondation **rétablit le nombre diploïde** (46 chromosomes), pas haploïde.
    
- **B** : Le sexe du zygote est déterminé par le spermatozoïde (X ou Y).
    
- **C** : Le gonosome du spermatozoïde détermine le sexe.
    
- **D** : La **recombinaison génique** (brassage) crée un nouveau génome.
    
- **E** : La fécondation **déclenche la segmentation**.
    

**Question 2**

**Réponse : D**

- **A** : Les signes de grossesse (nausées) apparaissent plus tard, mais la **beta-HCG** est détectable à 3 semaines.
    
- **B** : La **gastrulation** a lieu à la 3e semaine.
    
- **C** : La **beta-HCG** est présente dans les urines vers la 3e semaine.
    
- **D** : La **nidation** a lieu à la fin de la 1re semaine (J6-7), donc **faux**.
    
- **E** : La **neurulation** débute à la 3e semaine.
    

**Question 3**

**Réponse : E**

- **A** : Le tractus thyréoglosse est un vestige endodermique (thyroïde).
    
- **B** : La gouttière laryngo-trachéale est un diverticule endodermique.
    
- **C** : L'œsophage dérive de l'endoderme.
    
- **D** : Le bourgeon pancréatique dorsal est endodermique.
    
- **E** : Les bourgeons rénaux viennent du **mésoderme intermédiaire**, pas de l'endoderme.
    

**Question 4**

**Réponse : B**

- **A** : Le cordon ombilical apparaît à la **4e semaine**.
    
- **B** : Il contient **2 artères et 1 veine** (inverse dans l'option).
    
- **C** : Les artères véhiculent le sang **désoxygéné** vers le placenta.
    
- **D** : La veine amène le sang **oxygéné** au fœtus.
    
- **E** : La gelée de **Wharton** est présente.
    

**Question 5**

**Réponse : D**

- **A** : Les pyramides de Malpighi sont dans la **médullaire**.
    
- **B** : Leur base est orientée vers le **cortex**.
    
- **C** : Le sommet forme la **papille** dirigée vers le hile.
    
- **D** : Les **[[pyramides de Ferrein]]** sont les **rayons médullaires** (prolongements corticaux), pas la base des pyramides.
    
- **E** : Les papilles débouchent dans les **calices**.
    

**Question 6** [[Thymus]]

**Réponse : A**

- **A** : Les lymphocytes T immatures (thymocytes) sont dans le **cortex** (sombre).
    
- **B** : Cortex clair : moins de cellules.
    
- **C** et **D** : La médullaire contient des lymphocytes **matures**.
    
- **E** : Faux, ils sont surtout corticaux.
    

**Question 7**

[[Hémogramme - Numération Formule Sanguine (NFS)]]

**Réponse : A** (à vérifier)

- **A** : Les lymphocytes sont produits dans les **organes lymphoïdes** (moelle, thymus, ganglions).
    
- **B** : Le noyau du monocyte est **réniforme**, pas bilobé.
    
- **C** : Le taux normal est **4000-10000/mm³**, donc 4000-7000 est trop restrictif.
    
- **D** : Le neutrophile a un noyau **segmenté**.
    
- **E** : Les monocytes sont **2-10%** de la formule.
