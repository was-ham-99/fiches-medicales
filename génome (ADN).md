

 L'[[génome (ADN)]] mitochondrial (ADNmt) a des caractéristiques propres qui le distinguent de l'ADN nucléaire.

La réplication de l'ADN mitochondrial est **indépendante du cycle cellulaire**. Elle peut avoir lieu en permanence dans la cellule, contrairement à l'ADN nucléaire qui est répliqué pendant la phase S.
        
- **A : Vrai.** L'ADNmt a un **taux de mutation élevé** car il est exposé aux radicaux libres produits par la chaîne respiratoire et ses systèmes de réparation sont moins efficaces.
        
    - **C : Vrai.** La transmission est **uniquement maternelle** (uniparentale).
        
    - **D : Vrai.** Le code génétique mitochondrial est plus "économique", avec des gènes qui peuvent se chevaucher.
        
    - **E : Vrai.** L'ADNmt humain est une petite molécule circulaire qui code pour **37 gènes** (13 protéines, 22 ARNt, 2 ARNr).
